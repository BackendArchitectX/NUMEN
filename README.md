# NUMEN

**AI-Powered Data Intelligence Platform**

NUMEN turns a natural-language business requirement into a managed data-collection workflow, gathers information from permitted sources, validates and deduplicates records, preserves source provenance, and exposes the resulting dataset through a live dashboard.

> Built for the AI-Powered Data Intelligence Platform challenge. The project is designed to run without paid AI credits: a deterministic planner is included by default, with an optional local Ollama-compatible planner.

## Core capabilities

- Natural-language prompt to workflow plan
- Permitted-source collection with URL safety controls
- Live task progress over Server-Sent Events
- Cleaning, validation, quality scoring, and SHA-256 deduplication
- Source-backed provenance and evidence hashes
- Search, filters, task history, cancellation, and CSV export
- React + TypeScript dashboard
- Spring Boot backend with a production-ready layered architecture
- Docker Compose and one-command launch scripts

## Stack

Java 17 · Spring Boot 3 · React · TypeScript · Vite · PostgreSQL · Docker · Maven · GitHub Actions
