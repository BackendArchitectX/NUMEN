# NUMEN Demo Script

## 3-minute judge flow

1. Run `start.bat` on Windows or `./start.sh` on macOS/Linux. No backend/frontend terminal split is required.
2. Show the green **ENGINE ONLINE** indicator.
3. Submit: `Find Java backend engineering roles in India and structure title, company, location, URL and source.`
4. Point out the live seven-stage workflow: Interpret → Discover → Collect → Normalize → Validate → Deduplicate → Publish.
5. Show quality scores and source provenance in the dataset explorer.
6. Search `Java`, apply the `90%+` quality filter and export CSV.
7. Submit a prompt with an explicit permitted public URL to demonstrate real web collection.
8. Open recent workflow history and explain that PostgreSQL persists runs and Flyway owns the schema.
9. Close with the safety story: public HTTP(S) only, private-network blocking, redirect blocking, timeout/body-size limits and labelled offline-demo data.
