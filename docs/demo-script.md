# 3-minute demo script

1. Start with `docker compose up --build` and open `http://localhost:5173`.
2. Submit: **Find Java backend engineering roles in India and structure title, company, location, URL and source.**
3. Point out the seven workflow stages and live SSE progress.
4. Show the resulting dataset, quality scores and source provenance.
5. Search for `Java`, filter to `90%+`, then export CSV.
6. Submit a second prompt containing an explicit permitted public URL to demonstrate live web collection.
7. Open Workflow History to show that previous runs remain persisted.
8. Mention SSRF protection, deduplication fingerprints and the zero-paid-credit architecture.
